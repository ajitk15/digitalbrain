Using it

REST

{{ base }}{% url 'api-graph-search' application.pk %}
Example request
curl -H "Authorization: Bearer YOUR_TOKEN" "{{ base }}{% url 'api-graph-search' application.pk %}?q=which+servers+run+under+NODE1"

Returns matching relationships with the source document and the exact quoted evidence for each. Add &version=2 to pin a graph version; without it the latest published version answers, never a draft. Every response states the version that produced it.

MCP

{{ base }}{% url 'api-mcp' application.pk %}

Exposes one tool, search_knowledge_graph, taking a question and an optional version. Rate limit: 120 requests per minute per token.

Connect a client

One command. Add --scope user to make it available in every project rather than just this one.

Terminal
claude mcp add --transport http digital-brain \
  {{ base }}{% url 'api-mcp' application.pk %} \
  --header "Authorization: Bearer YOUR_TOKEN"

Settings → Developer → Edit Config, then restart Claude.

OpenAI reaches this endpoint from its own servers and requires a public HTTPS URL, so a localhost address cannot work. Publish this application behind HTTPS first.

In ChatGPT: turn on Developer mode under Settings → Security, then add the server under Settings → Connectors. From the API, pass the token as authorization — OpenAI discards arbitrary headers.

pip install mcp for the client below, or skip MCP entirely and call the REST endpoint.

MCP client
import asyncio, os
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

URL = "{{ base }}{% url 'api-mcp' application.pk %}"
HEADERS = {"Authorization": f"Bearer {os.environ['DIGITAL_BRAIN_TOKEN']}"}

async def main():
    async with streamablehttp_client(URL, headers=HEADERS) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()
            result = await session.call_tool(
                "search_knowledge_graph",
                {"question": "which servers run under NODE1"},
            )
            payload = result.structuredContent
            print("answered from version", payload["version"])
            for row in payload["results"]:
                print(row["source_title"], "-", row["evidence"])

asyncio.run(main())

MCP is JSON-RPC over POST. Useful for checking a token before wiring up a client.

List the tools
curl -X POST "{{ base }}{% url 'api-mcp' application.pk %}" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
Call the tool
curl -X POST "{{ base }}{% url 'api-mcp' application.pk %}" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"search_knowledge_graph","arguments":{"question":"which servers run under NODE1"}}}'

Using it

REST

{{ base }}{% url 'api-graph-search' application.pk %}
Example request
curl -H "Authorization: Bearer YOUR_TOKEN" "{{ base }}{% url 'api-graph-search' application.pk %}?q=which+servers+run+under+NODE1"

Returns matching relationships with the source document and the exact quoted evidence for each. Add &version=2 to pin a graph version; without it the latest published version answers, never a draft. Every response states the version that produced it.

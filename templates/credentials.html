How this is stored

A credential saved here is written to a file readable only by the service account, exactly as an operator-mounted one is. It is never stored in the database, never written to the audit log, and never sent back to the browser — the digest beside it is all that identifies it afterwards. Saving again overwrites the file; Remove deletes it.

The platform's own secrets — the signing key and the database password — are deliberately not listed here. The service cannot start without them, so they stay with your operator.

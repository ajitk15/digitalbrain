Provider credentials and model availability

Mount the OpenAI API key as {{ openai_secret }} and the Anthropic credential as {{ claude_secret }} in the configured secret directory. Credentials stay outside .env and the database.

Claude accepts either credential, and the file contents decide which is used. An API key (sk-ant-api…) bills your Console account. An OAuth token from claude setup-token (sk-ant-oat…) bills a Claude subscription instead and needs no interactive sign-in on the server. Each application still uses its own mounted credential; the runtime never falls back to a login stored on the host, so one application can never spend another's budget or the operator's.

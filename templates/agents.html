Agents

An agent is AI that chooses what to read before it answers: it calls read-only tools, looks at what they return and decides what to read next. Each one runs on the server, inside the same harness, which checks access on every call, verifies what comes back and records every step.

Wherever one runs, its {% icon "agent" 14 %}AgentOn badge sits beside the control that starts it and says whether its next run will be one; whatever it made by reading further carries an {% icon "agent" 13 %}AgentN steps tag. AI settings and Features carry each agent's badge on the task and the feature it runs under.

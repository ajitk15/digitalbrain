# CarePath graph-generation videos

Two four-minute editions of the CarePath document-to-knowledge-graph teaching video. Both use Indian-English synthesized narration, a growing circular-node graph, a left-hand step list and compact captions.

Each folder also includes a poster and verification record. Videos are 1920 x 1080 at 24 fps, H.264 with AAC audio, burned-in captions and a selectable subtitle track. Download the MP4 if GitHub does not offer playback.

## Example and scope

The example uses local CarePath user stories, architecture and traceability documents under `demo-artifacts/docs`. The files were converted with MarkItDown and the selected prepared AI proposals were checked using the project graph builder, evidence validator and entity merger.

The displayed graph is a focused subset of the complete graph. AI proposals, vector values, search and grouping visuals are teaching illustrations; the videos are not live application recordings. In v7, friendly display labels replace requirement IDs and code symbols while the original source evidence remains authoritative.

The two editions are preserved as review checkpoints for further refinements.

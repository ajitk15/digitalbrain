# Documentation

All of Digital Brain's documentation lives here.

| Folder | What it holds |
|---|---|
| [`engineering/`](engineering/index.html) | The engineering handbook (`index.html`: overview, architecture, how we build), design plans, end-to-end guides, the architecture poster, diagrams and leadership slides |
| [`product/`](product/index.html) | The product documentation site: user guide, deployment and technical reference. Open `product/index.html` in a browser |
| [`reviews/`](reviews/) | Review, revalidation and verification reports |
| [`demo/`](demo/README.md) | The CarePath demo corpus, demo kit, presentation material and tooling. **This is also the scorecard's test data**: code, tests and the Docker image read `demo/docs`, `demo/carepath` and `demo/demo-kit` at these paths, so don't move or delete them |

`README.md` and `CLAUDE.md` stay at the repository root. `deploy/README.md` and `benchmarks/README.md` describe their own folders.

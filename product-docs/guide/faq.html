Answers and trust

Can I trust an answer?

Trust its citations, and check the ones that matter. Every citation was re-checked when the page was drawn: the source is still active, unchanged since it was cited, and contains the quoted words exactly. The sentences around the citations are written by a model and can still be wrong - which is exactly why the quotes are there. How the check works.

Why did an answer say it found nothing?

Most often: the information is not in any active source yet; the source is restricted (never sent to AI); the document is still converting; or, in Graph answer mode, the newest version has not been published. An answer that cites nothing is offered to owners in Learned as a gap to fill.

I uploaded a document - why isn't it in Graph answers?

Graph answers read the published version. Your upload built a new draft; an owner or contributor publishes it on Knowledge → Versions (or it publishes itself, if an owner switched automatic publishing on and every check passed). Source excerpts and AI answers search current sources and see it as soon as it is converted.

What happens when a document changes?

The new text replaces the old as the active record (the old one is retired, not deleted). Any citation that pointed at the old wording stops verifying and disappears from answers and published versions immediately. A new draft graph version is built.

Does it learn from my questions?

Not by itself. Questions that got no citation, and answers marked Wrong answer?, become candidates in Knowledge → Learned. Only when an owner or contributor accepts one does it become a benchmark question that future versions are measured against. Your name is not shown with your question.

Access

Why can't I see an application my colleague uses?

You need a grant on that application. Without one it reads as "not found" - by design, the platform does not confirm that it exists. Ask one of its owners. Why.

I am an administrator - why can't I open an application?

Administering an organization or the platform grants nothing inside an application. An owner of that application, or the "Also grant me owner access" box when you create one, gives you a real, audited grant.

Does Microsoft sign-in give me access?

No. It proves who you are. What you can open is decided only by grants here.

I lost my phone with the authenticator app.

Use one of your recovery codes, or ask a platform administrator to remove the authenticator on your person page. (A platform administrator's own is removed by the operator on the server.)

AI and cost

Can I use Digital Brain without AI?

Yes. Source excerpts, the structural graph, source and content checks, code indexing, rule-based code review checks, the operations graph and every rule-based check call no model. Switch AI tasks off on AI settings.

Who pays for the AI?

The application whose credential is set. Each application has its own key and its own budget, and every call writes a receipt naming who asked. More.

What if the AI provider is down or busy?

The call fails and says so; nothing is retried on your behalf, so nothing is paid for twice. If too many calls are already running, a new one waits briefly and is then told nothing was sent. Source excerpts keep working because they use no model.

Where does my data go?

Only to the AI provider your application's owner configured, under that account. Restricted sources never go. Masking, when on, replaces chosen values before anything is stored. Digital Brain sends no email and attaches no tracking.

Code Factory and code

Will Code Factory change our code without asking?

No. A person approves the plan first. Delivery opens a pull request - merging it is yours. On a development or demonstration server it can instead write into an allowed local folder, checking every file against the indexed snapshot first and committing nothing.

Does Digital Brain run our code?

Normally never. The one exception is opt-in and refused in production: on a development or demonstration server, an approver can press a button to run a local folder's own test suite, with a five-minute limit.

Why was my Code Factory run refused?

Usually there is no published knowledge graph. A plan whose items cite nothing is the one thing the pipeline must not produce, so the run is refused at the button, again before any spending, and the plans screen explains it. Other gates are listed on Onboarding.

Operations

Can an automation run by itself?

No. Importing an automation never runs it, and Simulate run sends nothing. Real execution needs an owner's request, a job on the connection's allow-list, records that still verify, and - where required - approval by a different owner.

Why is a knowledge article from ServiceNow not in the operations graph?

It joins only while ServiceNow itself says it is Published and in date. That review, where the article is written, is the gate.

General

Is it HIPAA compliant?

Digital Brain implements the HIPAA technical safeguards of §164.312 - access control, audit controls, integrity, authentication and transmission security - and probes each on every change. Compliance as a whole also depends on how it is deployed and run (agreements with providers, backups, policies), which is your organization's to decide. The safeguards in detail.

Can I undo a delete?

Disabling is reversible; deleting is not. That is why deleting an organization, portfolio, product or application is offered only after it has been disabled, and needs its name typed exactly.

Does it work without JavaScript?

Yes. Every control is a real form. JavaScript only adds streaming answers, popups and in-place progress.

Which languages can it read from scans?

The container image installs English for OCR. Other languages are a deployment's choice of Tesseract language package.

AI gateway and cost control

Every paid model call passes one pipeline (gateway.py): the purpose's rule, the configuration, admission, the credential file, the adapter, the receipt, release, and the rule again. It was built here rather than bought, so provider keys, prices and retry rules stay under the platform's own invariants.

Purposes: a closed registry

gateway.PURPOSES names every kind of paid call and the switches and roles it needs, read before the call and again after it. It replaced an if/elif chain that had been written twice, slightly differently.

Every task starts on (ai.SEEDED_DISABLED is empty, kept as the mechanism) - a deliberate trade for an application that uses its model from day one. The one condition left is a credential: embeddings start on only where the application has its own OpenAI key, because Anthropic has no embeddings endpoint.

Admission: slots and reservations

  • One AIAdmission row per call in flight. At most max_calls_per_application (default 4) per application and max_calls_per_provider (default 16) across the deployment, so one batch cannot take every connection a provider allows.
  • Each reserves the call's most expensive outcome - every prompt character counted as a third of a token, plus the whole reply cap - so recorded spend plus calls in flight must stay under the cap. Two calls at the cap no longer both start.
  • Admission locks the application row (and a PostgreSQL advisory lock per provider) in a short transaction of its own. No lock is held across a provider call.
  • A caller waits slot_wait_seconds (default 30) and is then told nothing was sent - never retried for it.
  • A streamed answer holds its slot for the whole run, tool turns included. A row left by a dead process expires after admission_minutes (default 15); the maintenance lane sweeps it.

The monthly budget

budget.py, AIBudget (no row means no cap). The three choke points are ai.invoke_ai, ai.chat_configuration and embeddings.embed - a new paid path must call budget.check and go through gateway.admitted. It caps starting spend from recorded receipts at the entered rates: a call in flight is never cut off, and graph extraction that hits the cap keeps what it already paid for.

Prices belong to a model and are set once in the Prices table, which writes every AIConfiguration row using that model. A model new to an application takes the price it already has there, else its list price, else zero - flagged Not priced, because spend and therefore the budget would read $0.

Receipts

  • One AIUsage row per model turn, unique on the provider's request id. A multi-turn answer records one per turn.
  • A missing or malformed token count is an error, not a free request (agent_runtime/usage.py): providers bill for calls whose usage was not parsed.
  • A receipt is written for the application authorized before the call. It used to look the grant up again, so a grant revoked while the model answered lost the receipt of a call the provider billed.
  • AIUsage is deliberately not partitioned: PostgreSQL enforces a unique key across partitions only if it includes the partition key, so the same request could be recorded again in a new month.
  • Receipts are kept until [retention] usage_days is set; the floor is 400 days. They survive deleting their application.

A missing secret with the setting off is an error; it must never quietly become "spend the operator's account".

Measuring models

  • Drift - manage.py llm_drift <app> --as <user> --record sends the frozen benchmarks/drift-pack.json (about ten paid calls), scores extraction with the same judge and answers by their citation markers, and compares with the model's first and latest runs. Run after changing a model, prompt or provider. A new pack starts a new reference.
  • Typing - manage.py typing_pack measures AI document typing against person-labelled items.
  • Reranking - manage.py benchmark --rerank --as <user>.
  • Cost control in CI - the scorecard holds re-runs on unchanged sources at 0, calls after one source changes at 1, and calls past the budget or a full gateway at 0.

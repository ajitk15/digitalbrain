Technical

Technology choices and why

Every technology in pyproject.toml, the Dockerfile and the Compose files: what it does in Digital Brain, why it was chosen, and - where the code or its working notes record one - what was rejected instead.

Web framework and serving

TechnologyUsed forWhy
Python 3.12The whole platformBoth AI SDKs, MarkItDown, Graphify and Tree-sitter are Python-first; one language means one process can index, convert, rank and answer. requires-python allows up to 3.14.
Django 5.2Pages, forms, ORM, migrations, sessions, CSRF, authenticationServer-rendered HTML with real forms is what makes progressive enhancement a contract: every control works with JavaScript off. Django's security middleware (HSTS, SSL redirect, CSRF, clickjacking) and migration system are mature; the expand-then-contract migration rule is enforced by a test.
No JavaScript build stepstatic/*.js, plain scriptsA strict CSP (script-src 'self', no unsafe-inline) is easier to keep when scripts are files served as-is. Browser tests in Playwright run them for real.
waitressThe WSGI server where there is no RedisPure Python, runs on Windows and Linux alike, clears forwarded headers the proxy did not set. Without Redis a process can only follow its own answers, so there is nothing to gain from an event loop.
uvicorn + a2wsgiThe default wherever [redis] is setEach open answer stream under waitress held a request thread, so a process followed 12 readers at most. Under uvicorn a reader holds no thread: measured, 100 concurrent readers all received. a2wsgi keeps every non-stream request on the same WSGI app, so views, middleware and the CSP are unchanged. The router itself does the edge work uvicorn does not: trusted-proxy headers, 413 over the body limit, 411 with no length.
WhiteNoiseStatic files with hashed namesNo separate web server is needed in the container; the manifest gives cache-safe filenames.

Data

TechnologyUsed forWhy
PostgreSQL 16The record: every row the platform keepsFive features the platform depends on exist only here: row-level security (the second layer of tenant isolation), advisory locks (one maintenance holder, one migrator), FOR UPDATE SKIP LOCKED (job claims), stored generated tsvector columns with GIN (keyword search: 51 ms → 10 ms when the expression indexes became stored columns) and declarative partitioning (the audit table, by month). verify-full TLS and SCRAM throughout.
SQLiteLocal development without services; the throwaway database the scorecard can useZero setup. The code says plainly what it loses: no row security (the code's scoping is the only layer), no advisory locks (never run a separate worker beside a server that runs its own lanes), substring search instead of full text.
psycopg 3PostgreSQL driverCurrent driver for Django 5.2, binary wheels.
Redis 7.4Each answer's events as a stream; Stop; the per-token API rate limitLets an answer outlive its HTTP connection and lets more than one web replica serve the same answer. It holds copies in transit, never a record - so no volume, no persistence, noeviction, TLS and a password file.
S3 (boto3)Uploaded original files, when [originals] store = "s3"Originals are the bulkiest data and do not belong on a container volume. Every botocore default an environment variable could change - credentials, profile, endpoint, proxies, CA bundle - is stated explicitly, and a test plants each one to prove it is ignored.
numpyVector search over embeddings, in processUnit float32 vectors and a dot product are enough at this scale. Rejected: pgvector - deliberately left out until a library outgrows memory, so the production database did not change.

Reading content

TechnologyUsed forWhy
ClamAV (clamd or clamscan)Virus-scanning every upload before conversionFails closed: anything clamd does not answer OK or FOUND to is unscanned, and signatures older than seven days are refused. The daemon replaced a clamscan per file, which reloaded the whole signature database for every document.
MarkItDownWord, Excel, PowerPoint, PDF, HTML… to textOne converter for many formats, producing Markdown whose headings and tables the graph builder reads. It runs in a subprocess with socket.connect patched to raise and is never handed a URL - links are downloaded separately, through the one fetcher.
pypdf, pypdfium2PDF page reports; rendering text-less pages for OCRThe page report (pages, pages with no text) is read in the extractor before an original may be deleted.
TesseractOCR of scanned pages and imagesLocal, handed a file, no network call. Each page it read is headed with its confidence, so a citation from a scan says so; a low-confidence page marks the document's "Readable text" check missing.
defusedxmlParsing XML safelyRefuses entity-expansion and external-entity tricks in uploaded or imported XML.
PillowApplication logos, image handling for OCRValidates an uploaded image is really an image.

Reading code

TechnologyUsed forWhy
git (clone)Reading a GitHub repository for Code GraphThe REST path cost one request per file against an anonymous budget of 60 an hour. The clone takes only owner/name with a hardcoded github.com; hooks go to an empty directory, submodules are not followed, HOME and git config point at scratch, and the token is written to scratch config rather than argv. In a server folder git is never run - the commit is read from .git/HEAD as text.
Graphify (with Tree-sitter, graspologic-native)AST extraction, cross-file calls and inheritance; Leiden clustering for componentsDeterministic and local. Its LLM pass is never called: it would spend under Graphify's own key, bypassing per-application credentials and receipts, and its edges carry no quote to verify. Its search scorer was not reused either - it is private API tuned for code-symbol nodes. A Graphify failure degrades a snapshot to partial, never to none.
rapidfuzzMatching a long misspelt word when merging entity namesWord by word, numbers exact. Whole-string similarity was tried and merged carepath-api with carepath-api-green.

AI

TechnologyUsed forWhy
Claude Agent SDK (bundled Claude Code CLI)Agentic runs on Claude: chat with tools, Code Factory's agents; any call with a claude setup-token OAuth tokenGives the model real tools - exactly mcp__brain__search_knowledge and mcp__brain__fetch_source, confirmed against a live CLI - with every built-in tool disabled. The CLI ships inside the wheel and is not installed in the image; its HOME and CLAUDE_CONFIG_DIR point at an empty temporary directory, so no run inherits an operator's login.
anthropic SDKA one-shot Claude call with an API key - one Messages requestNo subprocess. The client is given the key and base URL explicitly, takes no proxy from the environment and drops ANTHROPIC_CUSTOM_HEADERS; a test plants all four.
OpenAI Agents SDKAgentic runs on OpenAI; embeddingsThe same tool contract on the other provider. The package owns the top-level agents module, which is why the platform's own is called agent_runtime.
The AI gateway (built here)Every paid call: purpose rule, admission, credential, adapter, receiptRejected: LiteLLM, Portkey or a cloud AI gateway - each would hold the provider keys and keep its own prices and retry rules, trading four invariants at once. So the gateway is a pipeline in front of the SDKs already used. Details.
Own ranking (BM25 + coverage + spread)Ordering citations for every answer pathMeasured, not assumed: "BM25 alone did not help; the spread did most of it". Graph answers went 11/16 → 15/16 found on the CarePath benchmark.

Identity and security libraries

TechnologyUsed forWhy
argon2-cffiPassword hashingArgon2 is Django's strongest hasher; a HIPAA probe checks it is first.
django-axesLockout after 5 failures for 15 minutes, by user and addressThe authenticator allows 3 tries so a person is sent back to the password before the lockout page.
PyJWT[crypto]Verifying Entra ID tokensRS256 only, by a key the tenant publishes (fetched through the one fetcher, never taken from the token), with exact iss, aud, tid and nonce.
cryptographySealing authenticator seeds with FernetUnder an HKDF key from the mounted signing key; the previous key stays readable as a fallback so rotation does not lock people out.

Operations

TechnologyUsed forWhy
Docker + ComposeEvery deployment and the development servicesOne image with build targets (runtime, demo); Compose files describe single-container, scaled and observability layouts. Development runs production's own images (PostgreSQL, Redis over TLS, clamd).
tiniPID 1 in the containerForwards SIGTERM so lanes stop between steps, never inside one.
uvLocked dependency installuv sync --frozen from uv.lock; botocore is held to the release published beside the pinned boto3.
OpenTelemetry SDKTraces and metrics over OTLP/HTTPA standard any collector reads. Rejected: the OTLP exporter's own HTTP sender, which merges headers, certificates and a CA from OTEL_EXPORTER_OTLP_* whatever it is given - the exporter is written here over the SDK's encoder.
Prometheus + collectorService-level rules and burn-rate alertsRules are generated from the SLO registry and checked by promtool in CI.

ruff, coverageLint and coverageOne fast linter for errors, imports, bugbear and upgrades.
fakeredisRedis streaming tests without a serverCI runs them again against a real Redis.

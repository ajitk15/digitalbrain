Secrets

  • Files, never environment variables or rows. configuration.read_secret refuses a file with any group or other permission bit on POSIX, or an empty one. .env accepts only SITE_ADMIN_USER_ID. Configuration tables ([database], [redis]) refuse a credential field outright.
  • Two directories, the operator's wins. secret_directory is mounted read-only; managed_secret_directory (unset by default) is where the Credentials screen writes, and must differ. A credential projected from a secret manager is never overridden by one typed in a browser.
  • Self-service was a deliberate trade. The old rule ended "never a form field". It now allows an owner to set credentials, written only by secrets.py as the same 0600 file; the value is never redisplayed, and ManagedCredential keeps who, when and a salted digest. django_secret_key and database_password are not manageable this way - the process could lock itself out.
  • Shared connector folder (unset by default) gives up per-application isolation for connectors only (jira, git_read, git_write, servicenow) and is consulted last. Model providers are never read from it, because billing depends on per-application keys.
  • Database password is sent as a SCRAM verifier computed in the process, so a server logging DDL logs no password.

The web edge

The exact Content Security Policy, asserted by test_security.py:

default-src 'none'; img-src 'self'; style-src 'self'; script-src 'self'; connect-src 'self';
form-action 'self'; base-uri 'none'; frame-ancestors 'none'
  • No unsafe-inline, no external origins. connect-src 'self' exists for the chat EventSource. Because style-src 'self' forbids writing styles from script, popups use the native <dialog>.
  • Permissions-Policy: camera=(), microphone=(), geolocation=(); X-Content-Type-Options: nosniff; Referrer-Policy: same-origin; X-Frame-Options.
  • Production: HSTS one year with subdomains and preload, SSL redirect, Secure cookies. manage.py check --deploy --fail-level WARNING runs on every container start, so a misconfiguration stops the deploy.
  • Cookies only on browser routes, bearer tokens only on /api/v1/: accepting both would make the API CSRF-able.
  • Requests over the body limit are refused before Django reads them (413; 411 with no length under uvicorn). X-Forwarded-* is believed only from the trusted proxy.

Outbound requests

fetching.py is the only place a user-supplied URL is retrieved. It resolves first, refuses private, loopback, link-local, multicast and reserved addresses (unless an operator named the host in fetch_allow_hosts), pins the connection to a validated address so DNS cannot change underneath it, dials each validated address in turn and sends the request once. http/https only, no redirects, 8 MB and 20 s caps, no credentials attached. The Code Graph clone is the one exception, and takes no URL.

Handling outside content

Scan before anything

ClamAV, fail closed, signatures at most seven days old. A first-boot daemon serving stale bundled signatures is refused until restarted.

Convert offline

The extractor subprocess patches socket.connect to raise; OCR is handed a file. A bucket original is copied to a private 0700 directory for the scan and extraction, removed after.

Sandbox container

Intake, code-graph and factory lanes run read-only with /tmp as tmpfs, every capability dropped, no-new-privileges, 512 processes and 6 GB.

Never run what it reads

git hooks redirected, no submodules, no git at all in a server folder. Code Factory never runs code - except opt-in local tests on an approver's press, refused in production.

Server folders inside operator roots

code_graph_local_roots unset by default; drive roots refused; paths resolved before judged; secret directories, symlinks, junctions and hidden folders never entered.

Model output is data

Never rendered as Markdown; every quote looked up; a model can choose no credential, model or tool beyond the two bound ones.

Identity providers

  • Entra ID (sso.py): code flow with PKCE, pinned to one tenant (common and organizations refused), RS256 by a tenant-published key, exact iss/aud/tid/nonce. First sign-in links by sign-in name only when exactly one user matches, is not linked elsewhere, and is not a platform administrator (an operator links those with manage.py link_sso). Groups and roles are never read.
  • SCIM (scim.py): off by default and a 404 while off; bearer token of 32+ characters from a mounted file; touches only accounts it created or one matched by sign-in name; never a platform administrator; groups refused; users deactivated, never deleted; every change audited by the non-login entra-provisioning account.

Retention

Nothing removes audit events or receipts by default. [retention] audit_days and usage_days set windows, refused below six years (HIPAA documentation, §164.316(b)(2)) and 400 days. The maintenance lane deletes oldest first in batches and logs counts, never rows. On PostgreSQL a whole monthly audit partition is dropped only when every row in it is past the window.

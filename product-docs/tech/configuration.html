Configuration reference

One TOML file, named by DIGITAL_BRAIN_CONFIG (or rendered by the container entrypoint), plus one file per secret. digitalbrain/configuration.py:load_config refuses any key it does not know, any credential inside the file, and every combination listed under "Refused".

Why A configuration that names things but never holds a credential can be committed, reviewed, diffed and rendered from environment variables safely. Refusing unknown keys turns a typo into a startup error instead of a silently ignored setting.

On POSIX each must be mode 0600 and owned by the process user (uid 10001 in the image). .env accepts only SITE_ADMIN_USER_ID.

Container environment variables

When no file is mounted at /etc/digitalbrain/production.toml, deploy/entrypoint.sh renders the configuration from these (none holds a secret):

DIGITAL_BRAIN_ROLEall (default), web, worker or migrate

Principles the schema follows

The converted text is the record

KnowledgeEntry.content and its digest are what every citation verifies against. A changed source supersedes (active=False) rather than updates, so a citation to the old text stops verifying.

Retire, do not delete

Pruning a connector's missing records, re-converting a document and replacing a code-docs source all set active=False. Deleting a level of the tree leaves a tombstone row with deleted_at, hidden by LiveManager.

A version is stored once per element

GraphElement holds each source, node and edge with first_number and last_number, so a rebuild after one change writes 1.4% of a version rather than all of it. Old versions' JSON is slimmed and refilled on load.

Order is explicit

A chat message has a sequence, because both halves of an exchange are written in one transaction and timestamps cannot order them.

No secret in a row

ManagedCredential records who set a credential, when, and a digest salted with the file name - never the value. ApiToken stores a SHA-256 digest.

Missing means default

No ApplicationFeature row means enabled; no AIBudget row means no cap. Only departures from the default are written.

Migrations

  • 108 migration files on main, numbered up to 0106. Since 0090, every migration must be one the previous release can run against (expand, then contract): add a column nullable or with a db_default; remove or rename only a release after the code stopped using it. test_migration_job.ExpandContractTests refuses anything else unless it is named as the second half of a pair.
  • 0088 added stored generated search_vector columns with GIN indexes; 0089 generated arrays for edge terms; 0091 row-security policies; 0092–0093 swapped the audit table to monthly partitions without copying a row.
  • A new table with a required application must be in the row-security policy list or the named UNSCOPED set - test_tenancy fails otherwise.

Glossary

Every term these pages use, in plain words. Each definition links to where the term is explained in full.

ABCDEFGHIJKLMOPRSTUVW
Admission
The gateway's permission for one paid call to start: a free slot for the application and the provider, and room in the budget for the call's most expensive outcome. AI gateway
Advisory lock
A PostgreSQL lock on a number rather than a row. Used so migrations are applied once, maintenance has one holder, and per-provider admission is counted correctly. Workers
AI answer
A chat mode where a model writes the answer from current sources it searched, citing them. Chat
Application
The unit of access and billing: its own knowledge, graph, credentials, budget and grants. How it is organized
Answerable
A source that is active and not restricted - the only kind any AI path may read or cite. Answering
Approval rights
A flag on a grant that lets its holder approve Code Factory plans and give approval rights to others. Roles
Audit event
A record of a control-plane change: who, what, when. Kept at least six years when a window is set. What is recorded
Automation
A runbook job (AWX, Rundeck, Azure Automation, a ServiceNow flow or a team's list) shown in the operations graph; "Simulate run" sends nothing. Automations
Benchmark
An owner's questions with the source each should find, scored against every saved version - free, no model. Check
BM25
A standard way of scoring how well a passage matches the words of a question; the second of three ranking keys. Ranking
Budget
An owner's monthly cap on an application's AI spend, checked before every paid call. Budget
Citation
A pointer from an answer to a source and the exact words quoted from it, verified before it is shown. Can I trust an answer?
Code Factory
The pipeline from a ticket to a reviewed plan to a delivered change, every step cited and approved by a person. Code Factory
Code
An index of a repository's files, symbols, routes and calls, read from a clone or a server folder. Code
Connector
A link to another system - Jira, GitHub, ServiceNow, SharePoint, automation tools - that imports its records as sources. Connectors
Content check
A document's score against the checks for its document type (sections, numbered requirements, owned actions...). Advice only. Build
Contributor
The role that can add and change knowledge, start Code Factory runs and triage incidents. Roles
CSP
Content Security Policy: the browser rule that only this server's own scripts and styles run. Pinned by a test. Web edge
Demonstration
Production mode with demo reset, local Code Factory delivery and the ServiceOps test workbench allowed - every other production rule kept. Hosted demonstration
Digest
A fingerprint (SHA-256) of a source's stored text. A citation stays valid only while its source's digest is unchanged. Verification
Document type
What a document is - requirements, ADR, runbook, postmortem and more - read from its own content by rules; a person's choice wins. Build
Draft
A saved graph version nobody has published yet. It can be measured, never answered from. Publish
Embedding
A list of numbers standing for a text's meaning, used only to choose starting points; never a citation by itself. Embeddings
Entra ID
Microsoft's directory. Sign-in through it authenticates and grants nothing. Identity providers
Expand and contract
Changing the schema in two releases - add first, remove later - so the previous release always runs against the new schema. Upgrades
Feature
A switch from one registry: Knowledge, Chat, Code, Code Factory, ServiceOps, connector kinds and more, chosen at creation. Features
Fingerprint
A digest over everything a graph is built from; when it moves, a rebuild is due. Jobs
Gateway
The one path every paid model call takes: purpose rule, admission, credential, adapter, receipt. AI gateway
Grant
A person's role on one application. No grant means the application reads as not found. No grant, no access
Graph answer
The chat mode that answers from the latest published graph version. Chat
Graph version (revision)
One saved build of the knowledge graph, numbered, never changed after it is saved. Graph and versions
Graphify
The code-analysis library used for its deterministic parts only: syntax trees, cross-file calls, clustering. Its model pass is never called. Reading code
Heartbeat
The timestamp each lane holder writes, so a stopped worker is told apart from a slow one. Health
HIPAA §164.312
The US health-privacy rule's technical safeguards: access control, audit, integrity, authentication, transmission security. HIPAA
Intake
Scan, convert and check an uploaded document - the first lane, run in the sandbox when split. Intake
Job
A row asking for background work, written in the same transaction as the change that needs it. Jobs
Keyword answer (Source excerpts)
The chat mode that returns verified passages from current sources, ranked, with no model call. Chat
Knowledge entry
One source's stored text - a converted document or an imported record. Citations verify against it. Data model
Lane
A named background loop - intake, graph, code-graph, factory, serviceops, serviceops-tests, automations, connectors, maintenance. Lanes
Learned
Candidates that using the platform produces - change records, incident learnings, gaps, wrong answers - offered for a person to accept, never written straight into knowledge. Learned
Managed credential
A credential an owner typed on the Credentials screen, written as a file in a separate directory; an operator's file always wins. Secrets
Masking
Replacing chosen personal data with a stable placeholder before a source is stored, so every reader sees only the placeholder. Your data
MCP
Model Context Protocol: lets an AI assistant call this platform's graph search and triage briefs with a bearer token. MCP tools
MRR
Mean reciprocal rank: 1 when the expected source is ranked first, 0.5 when second, and so on, averaged. Scorecard
Ontology
The closed list of entity types and relations AI extraction may use; anything outside it is refused. AI in the graph
Operations graph
Incidents, changes, articles and automations joined by rules, rebuilt live and re-verified when read. Operations graph
Originals
The uploaded files themselves, on disk or in a bucket; optional, because the converted text is the record. Originals
Owner
The role that manages an application: access, credentials, AI settings, budget, features. Roles
Passage (chunk)
A fixed-size window of a source's text, stored as a row for fast search; a copy, never evidence. Candidates
PHI / PII
Protected health information / personally identifiable information, found by labelled patterns and only ever suggested. Your data
Platform administrator
Runs the platform from Administration; opens no application without a grant. Administration
Published
The graph version that answers. Publishing is a person's step, or an owner's rule that a version passing every release check publishes itself. Publish
Purpose
One kind of paid AI call - chat, graph extraction, typing, review, triage, embeddings, reranking... - each with its own rules. Purposes
Receipt
The record of one model turn: provider request id, tokens, cost, application and person. Never silently zero. Receipts
Reranking
A model reorders verified citations; it can add or change none. Ranking
Restricted
A source no AI may read or cite; people with access still can. Source permissions
Row security (RLS)
A PostgreSQL rule on every table that lets a connection bound to one application read and write only its rows. Row security
Rules
A source an owner marked as rules - a coding standard, a control matrix. Its rule lines are read without AI and shown, quoted, beside a Code Factory plan they apply to; they never decide anything. Rules
Runtime role
digital_brain_runtime: the database login the platform serves with, able to touch rows and nothing else. The role
Sandbox
The locked-down container that runs intake, code-graph and factory - the lanes that hand outside content to other programs. Scaled split
Scorecard
The fifth gate: measures retrieval, citations, cost control, safeguards and speed against a baseline, with no model call. Scorecard
SCIM
A standard the directory uses to create and deactivate accounts here; it never grants access. SCIM
ServiceOps
Incident triage from runbooks, history and changes, every step cited. ServiceOps
SLO
Service-level objective: a measured target, such as "99% of answers end complete". Service levels
Source check
A document's 0-100 score on a fixed rubric; "Ready" needs 80 and no check missing. Advice only. Build
Structural graph
The graph built by rules alone - headings, tables, references - free and rebuilt automatically. Build
Tenant
One application, as row security sees it: the id a connection is bound to. Tenancy
Token (API)
A bearer secret standing for one person; it can do exactly what they can, and stops when their grant does. Tokens
Triage
ServiceOps' cited brief on an incident: what it resembles, what changed, which runbook applies. ServiceOps
Uvicorn / waitress
The two web servers: uvicorn wherever Redis is configured, so open streams hold no thread; waitress otherwise. Serving
Verified quote
Words a citation or relationship claims a source says, found exactly in that source's current text. Verification
Viewer
The role that can ask questions and read everything in an application. Roles
Walk
Following AI relationships up to two hops from the best matches; its finds come after every direct match. The walk
Worker
The container (or process) that runs the background lanes. Workers
